# task-management-system
## 📖 About

Task Management System is a full-stack web application developed to help users efficiently organize, manage, and track their daily tasks. The application provides a simple, responsive, and user-friendly interface for creating, updating, deleting, and monitoring tasks.
## ✨ Features

- Create Tasks
- Update Tasks
- Delete Tasks
- View All Tasks
- Mark Tasks as Completed
- Task Status Management
- Responsive User Interface
- ## 🛠 Technology Stack

### Backend
- Java
- Spring Boot

### Database
- MySQL

### Tools
- Git
- GitHub
- Maven

- ## ⚙ Installation
